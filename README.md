# macos-smart-ime

Local workspace for the macOS smart input method project.

The input method is shown to users as **LinguaType** (灵译输入法 on Chinese systems). Internally the app bundle, executable, bundle identifier (`lab.dcyber.inputmethod.smartime`), and scripts keep the name `SmartIMEHost`. Icons are generated by `scripts/branding/make-icons.swift`.
