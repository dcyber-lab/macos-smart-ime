# English Engine Data License

## `Sources/EnglishEngine/Resources/wordlist.txt`

The English completion lexicon is generated by `scripts/english/build-wordlist.py`
from the word frequency data in [wordfreq](https://github.com/rspeer/wordfreq)
3.1.1 by Robyn Speer.

- The word list is a derivative of wordfreq's data and is licensed under
  [CC-BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
- It keeps the top 100,000 lowercase `[a-z]+` English words in frequency order,
  and drops profanity and slurs (an exact-word list plus unambiguous stems such
  as "fuck" or "shit", with an allowlist for names like "Yamashita") so they are
  never offered as completions.
- This license applies only to the data file, not to the project source code.

### Upstream attribution

wordfreq's data is built from the following sources:

- Google Books Ngrams (<http://books.google.com/ngrams>) and Google Books
  Syntactic Ngrams
- The Leeds Internet Corpus, University of Leeds Centre for Translation Studies
- Wikipedia (<http://www.wikipedia.org>)
- ParaCrawl (<https://paracrawl.eu>)
- OPUS OpenSubtitles 2018 (<http://opus.nlpl.eu/OpenSubtitles.php>), with data
  originating from OpenSubtitles (<http://www.opensubtitles.org/>)
- SUBTLEX word lists by Marc Brysbaert et al., freely available at
  <http://crr.ugent.be/programs-data/subtitle-frequencies>
- Word statistics collected from the Twitter streaming API

Citation: Robyn Speer. (2022). rspeer/wordfreq: v3.0. Zenodo.

## `Sources/EnglishEngine/Resources/supplement.txt`

Project-authored list of technical and office terms with their preferred
casing and a hand-written Chinese gloss (for example `GitHub<TAB>代码托管平台`,
`OKR<TAB>目标与关键成果`). It is part of this project's own source and is not
derived from wordfreq, CC-CEDICT, or ECDICT.

## `Sources/EnglishEngine/Resources/en-zh.tsv`

Short Chinese glosses shown next to English candidates, generated by
`scripts/english/build-glosses.py` from
[ECDICT](https://github.com/skywind3000/ECDICT) by skywind3000
(commit `bc015ed2`, 2025-03-28, MIT License, Copyright (c) 2017 Linwei), with
the supplement's hand-written glosses taking precedence. The 2,000 most common
words are not glossed.

## `Sources/EnglishEngine/Resources/zh-en.tsv`

The Chinese-to-English translation table is generated by
`scripts/english/build-translations.py`. Each headword takes its translations
from the first of these sources that has it:

1. `Data/zh-en-supplement.tsv`: hand-written translations of developer terms
   (for example `内核空间<TAB>kernel space`). This file is part of this project's
   own source and is not derived from any of the sources below.
2. [CC-CEDICT](https://cc-cedict.org/) (release 2026-09-30, distributed by
   [MDBG](https://www.mdbg.net/chinese/dictionary?page=cc-cedict)). Glosses
   marked "(computing)" and the like come first.
3. The `[计]` (computing) senses of
   [ECDICT](https://github.com/skywind3000/ECDICT) (commit `bc015ed2`, MIT
   License, Copyright (c) 2017 Linwei), reversed, for headwords CC-CEDICT lacks.

- The table is a derivative of CC-CEDICT and is licensed under
  [CC-BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
- It keeps simplified headwords of two or more characters with at most two
  English translations each. CC-CEDICT cross-references, classifiers, and long
  descriptions are removed.
- The build reads no GPL-licensed data (the rime-ice tables are not an input).
- This license applies only to the data file, not to the project source code.

CC-CEDICT is maintained by the CC-CEDICT community and is based on the original
CEDICT by Paul Andrew Denisowski.
