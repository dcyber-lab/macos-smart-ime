# Agent Entry

Use `AGENTS.md` in this directory as the primary project instruction file.

Before changing code, read:
1. `docs/project-brief.md`
2. `docs/technical-design.md`
3. `docs/openspec-workflow.md`
4. `docs/implementation-log.md`
5. `docs/git-workflow.md`

For any new feature, do not implement first. Create or update the relevant OpenSpec change in `openspec/changes/` and only start coding when the feature is implementation-ready.

Follow the Git workflow and documentation sync rules defined there.
